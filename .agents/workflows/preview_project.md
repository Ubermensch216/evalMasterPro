# Preview Project Workflow

This workflow launches the local Next.js development server for EvalMaster Pro.

## Steps

1. Start development server on port 9002 (or default 3000):
   ```bash
   npm run dev
   ```

2. Open browser at:
   ```
   http://localhost:9002
   ```

3. (Optional) Run Genkit AI dev flow:
   ```bash
   npm run genkit:dev
   ```
