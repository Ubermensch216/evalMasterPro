# **App Name**: EvalMaster Pro

## Core Features:

- 홈 페이지: 홈 페이지: 시스템 이름(로고 포함), 평가 위원, 관리자, 채점 결과 페이지 메뉴 배치
- 채점 페이지: 채점 페이지: 평가위원은 드롭박스에서 자신의 이름을 선택하고 비밀번호를 입력하여 접속. '기타 의견'란에 300자 텍스트 입력 가능. 채점 완료 시 DB에 저장 및 중복 방지. 채점 완료 후 수정 불가 안내. 채점 대상자 전체 조회 페이지에서 채점 여부 및 점수 조회.
- 관리자 페이지: 관리자 페이지: 관리자만 접속 가능. 이원화된 비밀번호 관리(일반/절대). 관리자는 평가위원, 평가 대상자, 평가 항목을 추가, 삭제, 수정 가능. 평가 항목별 배점 설정 가능. 채점 결과 집계, 초기화 기능 제공.
- 채점 결과 조회: 채점 결과 조회 페이지: 평가위원들의 채점 결과를 집계하여, 평가 대상자별 총점, 평균 점수 및 전체 등수를 파악. 상세 보기는 없음.
- 개인별 평가 조회: 평가 대상자 별로 평가 위원들의 점수를 팝업으로 확인 가능한 페이지
- 평가위원별 평가 내역 조회 및 출력: 평가위원 별로 자신이 평가한 모든 평가 대상자에 대한 평가 내역을 조회하고 출력할 수 있는 페이지 제공. 페이지 하단에 서명란 추가.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to represent trust, stability, and professionalism.
- Background color: Light gray (#F5F5F5) for a clean, neutral backdrop that ensures readability.
- Accent color: Soft amber (#FFB300) to highlight key interactive elements and call to action buttons, providing a gentle contrast and guiding the user's focus.
- Body font: 'PT Sans' (sans-serif) for clear readability in reports and general text. Headline font: 'PT Sans' (sans-serif) to maintain consistency and clarity.
- Use simple, professional icons for navigation and actions. All icons should be in the primary color, amber for 'call to action' and grayscaled for read-only
- Maintain a clean, structured layout with consistent spacing. Ensure report sections are clearly defined, enhancing readability and overall organization. Consistent column widths in tables.
- Use subtle animations, such as fading in elements upon loading or gentle transitions between pages, to enhance the user experience without being distracting.
